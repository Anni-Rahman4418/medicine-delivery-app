# 💊 Medicine Delivery App

## 📌 Project Overview

**Medicine Delivery App** is an on-demand healthcare platform that connects customers with local pharmacies through a single digital marketplace. The application allows users to browse available medicines, upload prescriptions (if required), place orders, make secure online payments, and track deliveries in real time. By providing a fast, reliable, and convenient medicine ordering experience, the platform helps customers access essential healthcare products while enabling local pharmacies to expand their reach.

## ✨ Features

* User Registration and Login
* Browse Medicines by Category
* Search Medicines
* Upload Prescriptions
* Add Medicines to Cart
* Secure Online Payment
* Real-Time Order Tracking
* Order History
* User Profile Management
* Pharmacy Dashboard
* Inventory Management
* Admin Dashboard
