Medicine Delivery App is an on-demand healthcare platform that connects customers with local pharmacies through a single digital marketplace. Users can browse medicines, upload prescriptions, place orders, make secure payments, and track deliveries in real time, providing a fast, reliable, and convenient medicine delivery experience

---

## Project layout

- [`backend/`](./backend) - FastAPI + sqlite REST API (users, medicines, prescriptions, orders, payments). See [backend/README.md](./backend/README.md) for setup.
- [`frontend/`](./frontend) - React + TypeScript client. See [frontend/README.md](./frontend/README.md) for setup.
- [`doc/`](./doc) - business/product docs (problem statement, PRD, personas, etc.)
